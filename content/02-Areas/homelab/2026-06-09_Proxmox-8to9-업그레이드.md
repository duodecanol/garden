# Proxmox VE 8 → 9 업그레이드

PVE 9 는 **Debian 13 (Trixie)** 기반. 배포판 베이스가 바뀌는 메이저 업그레이드라 신중하게 진행한다. 실측: `pve-manager/9.1.9`, kernel `6.8.12-9-pve` 정상.

> [!warning] 사전 필수
> 시작 전 **모든 VM/CT 백업**. 클러스터는 노드를 하나씩 순차 업그레이드하며 쿼럼(Quorum) 유지에 주의.

## 1. 업그레이드 절차

```bash
# 1) 현재 시스템 최신화
apt update && apt dist-upgrade

# 2) 호환성 체크 스크립트 ([FAIL] 은 반드시 해결 후 진행, [WARN] 은 확인)
pve8to9

# 3) 리포지토리 bookworm → trixie 치환
sed -i 's/bookworm/trixie/g' /etc/apt/sources.list
sed -i 's/bookworm/trixie/g' /etc/apt/sources.list.d/pve-install-repo.list
#   Ceph 사용 시 Ceph 리포지토리 파일도 동일하게 수정

# 4) 실제 업그레이드
apt update && apt dist-upgrade

# 5) 재부팅 후 버전 확인
reboot
pveversion
```

## 2. 사후 관리

```bash
apt autoremove --purge      # 이전 버전 잔여 패키지 정리
systemctl --failed          # 실패 서비스 점검 (있으면 journalctl -u <svc> -e)
```

- Web GUI / `vmbr0` 등 네트워크 브릿지 / LVM·ZFS·Ceph 스토리지 `Active` 확인
- 중요 VM·CT 하나씩 기동해 콘솔·게스트 에이전트 통신 확인

## 3. 무료 운영을 위한 리포지토리 정리

구독권이 없으면 Enterprise repo 가 `401 Unauthorized` 를 뱉는다. 비활성화 + No-Subscription 등록.

```bash
# Enterprise repo 비활성화
mv /etc/apt/sources.list.d/pve-enterprise.list /etc/apt/sources.list.d/pve-enterprise.list.bak

# No-Subscription repo 등록 (PVE 9 / Trixie)
echo "deb http://download.proxmox.com/debian/pve trixie pve-no-subscription" \
  > /etc/apt/sources.list.d/pve-install-repo.list

# (선택) Ceph No-Subscription
echo "deb http://download.proxmox.com/debian/ceph-squid trixie no-subscription" \
  > /etc/apt/sources.list.d/ceph.list

apt update
```

| 리포지토리 | 용도 | 특징 |
|---|---|---|
| Enterprise | Production | 가장 안정 · 유료 구독 필요 |
| **No-Subscription** | 일반/테스트 | 무료 · Enterprise보다 빠른 업데이트 · 충분히 안정 |
| Test | 얼리어답터 | 최신 기능 · 버그 가능 |

## 4. 추가 권장 설정

- **"No Valid Subscription" 팝업 제거** — `proxmoxlib.js` 패치 후 `systemctl restart pveproxy`
- **CPU 마이크로코드** — `non-free-firmware` 섹션 활성화가 선행이어야 설치됨.
  ```bash
  sed -i 's/trixie main/trixie main contrib non-free-firmware/g' /etc/apt/sources.list
  apt update && apt install intel-microcode   # AMD: amd64-microcode
  # 적용 후 reboot, dmesg | grep microcode 로 revision 확인
  ```
  > [!note] 함정: `Package intel-microcode has no installation candidate`
  > 펌웨어/마이크로코드는 `main` 이 아니라 **`non-free-firmware`** 섹션에 있다. 위 sed 로 섹션을 먼저 추가해야 설치된다.
- **SSD Trim (ZFS)** — `zpool set autotrim=on <풀>`
- **PBS(Proxmox Backup Server)** 검토 — 증분 백업 + 중복 제거
- **이메일 알림** — Datacenter > Notifications (Gmail/Naver SMTP)
- 다크모드: User > Color Theme > Proxmox Dark
